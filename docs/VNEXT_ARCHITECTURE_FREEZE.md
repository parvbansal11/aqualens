# VNEXT architecture freeze

**Learned:** frozen YOLO11s candidate generator. Natural Clutter Suppressor v1 is retained as immutable `REJECTED_FOR_AUTOMATIC_SUPPRESSION` provenance and may be represented only as nullable `ADVISORY_ONLY` experimental evidence; it is never an automatic veto. RF-DETR is `UNAVAILABLE`; no trained artifact is registered.

**Algorithmic / physics:** condition measurement, shadow validation, deterministic persistence/contact association, change matching, and priority rules. Shadow evidence is never artificiality evidence by itself. Sequential-ping evidence requires an explicit source recording contract and genuine ping metadata; ZIP/filename order is not temporal evidence.

**Statistical:** future validation-calibrated evidence confidence. Current `UNVALIDATED_EVIDENCE_FUSION` is an evidence score, not a probability.

**Human:** append-only review, relabel, rejection reasons, and uncertainty.

**Demo-only:** the isolated existing SHIPWRECK presentation/recovery heuristic remains demo-only and does not alter raw YOLO confidence.

Runtime availability uses `AVAILABLE`, `UNAVAILABLE`, `NOT_CONFIGURED`, or `FAILED` where an adapter can report a failure; absent optional adapters are `NOT_CONFIGURED`.

The primary runtime object is `CONTACT`. Raw YOLO output is immutable observation evidence. `EVIDENCE SCORE` always has score type `UNVALIDATED_EVIDENCE_FUSION`, explicit versioned components/weights, and missing-channel disclosure. It is not a probability.
